Student Innovation Project

MemoryLens

A task-support application for Meta display glasses designed for people living with early-stage Alzheimer’s disease or other memory loss.

01

Innovation claim

MemoryLens extends a mobile task manager to smart glasses so wearers can receive hands-free reminders and respond by voice or gesture. Its caregiver log preserves uncertainty by separating completed, skipped, dismissed, and unanswered prompts.

02

Project description

The MVP includes caregiver task scheduling, a glasses reminder interface, four response states, a secure activity log, and follow-up alerts for unanswered high-priority prompts. It will not diagnose disease, verify medication use, or store continuous video.

03

Created value

Prompts appear within the wearer’s field of view without requiring a phone. Authorized caregivers receive clearer follow-up information while the design limits unnecessary surveillance.
