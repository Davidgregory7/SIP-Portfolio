## MemoryLens MVP

The repository now includes a hardware-independent MemoryLens proof of concept:

- `mvp.html` — wearable simulation and caregiver dashboard
- `mvp.css` — responsive, accessible interface styling
- `mvp.js` — reminder scheduling, response logging, dashboard summaries, and browser storage

The MVP runs entirely in a web browser and does not require Meta Ray-Ban Display glasses. It demonstrates the planned user workflow without claiming direct hardware compatibility.
