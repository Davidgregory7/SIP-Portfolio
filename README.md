# David Gregory — SIP / Boards Portfolio

Static GitHub Pages portfolio for UAT SIP311. The site includes Home, SIP, Boards, Projects, and Contact sections.

## Before submitting

1. Add David's preferred UAT/contact email to the Contact section in `index.html`.
2. Replace `YOUR_EMAIL` in the commented `mailto:` line in `script.js`, then enable that line.
3. Add the Week 4 SIP Brief link or embedded document.
4. Add the MemoryLens code repository link when development begins.

## GitHub Pages

Upload these files to the root of a public GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.
